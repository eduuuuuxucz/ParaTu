# Carta animada rosa

Una carta interactiva en Java inspirada en Cinnamoroll.

## Ejecutarla en VS Code

1. Abre `PatriciaBouquet.java`.
2. Pulsa **Run** sobre el metodo `main` o presiona `F5`.
3. Toca o haz clic en cualquier parte de la ventana.

La animacion abre el sobre, estira la carta y despues revela el texto poco a poco.

## Editar el mensaje

Escribe tu carta en `carta.txt`, guarda el archivo y vuelve a ejecutar el programa.
